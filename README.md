# Meteor Rush 
Meteor Rush is a fast-paced 2D arcade shooter developed in Unity and set in the depths of outer space. Players take control of a spacecraft navigating through dangerous asteroid fields while battling challenging waves of meteors. Quick reflexes, precise movement, and strategic shooting are essential to survive.

---

## Controls

| Action | Key |
|---|---|
| Move Left | A / Left Arrow |
| Move Right | D / Right Arrow |
| Shoot | Left Mouse Button |
